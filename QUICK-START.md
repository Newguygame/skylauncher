# SkyLauncher — quick setup

## 1. Run the local Windows installer (no GitHub download)

Download **SkyLauncher-Windows-Local-Setup.exe** from this delivery. Double-click it, choose whether to create a desktop shortcut, and launch SkyLauncher.

- The installer **contains SkyLauncher.jar**. It does **not** fetch SkyLauncher from GitHub or download any installer packages.
- This small installer needs **Java 17 or newer already installed** on that Windows PC. If Java is not installed, it tells you instead of downloading anything.
- The **full offline installer with Java bundled** can be built on Windows by running `build-windows-full-offline.ps1` (requires JDK 21+ and WiX), or automatically in GitHub Actions. Once built, the full installer needs neither Java nor internet during installation.
- Running Minecraft itself still requires internet to obtain game files and sign in, if these were not previously downloaded. SkyLauncher also has an optional normal startup update check from GitHub; it does not affect the **installation**.

## 2. Upload the GitHub project

1. Extract **SkyLauncher-GitHub-Project.zip**, and upload **the contents** to the root of `https://github.com/Newguygame/skylauncher` on `main` (keep `.github/workflows/build.yml` and `docs/`).
2. At **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/docs`, then save.
3. After deployment, the website should appear at `https://newguygame.github.io/skylauncher/` (subject to GitHub publishing).

## 3. Produce installer files for the website

1. In the GitHub repository, open **Actions → Build SkyLauncher native offline installers → Run workflow**. Download artifacts to test them. The Windows `.exe`, macOS `.dmg`, and Linux `.deb` generated by this workflow **bundle the launcher and Java** and do not download GitHub files during installation.
2. To make downloads available on your website, create a version tag such as `v3.1.1` and push it. The workflow builds and publishes the platform installers and `SkyLauncher.jar` to a **published GitHub Release** automatically (provided Actions has write access to Releases).
3. Website buttons automatically find matching installer files in the **latest published GitHub Release**. You do not have to edit download URLs.

## 4. Your own icons

No icon artwork is included. Optional files: `icons/SkyLauncher.ico` (Windows), `icons/SkyLauncher.icns` (macOS), `icons/SkyLauncher.png` (Java/Linux), and `docs/icon.png` (website). Add files later and rebuild. There is no need to add blank image files.

CurseForge integration is not included yet. Keep Minecraft instances in the existing `~/.ghmodlauncher` folder; launcher updates should not erase it.
