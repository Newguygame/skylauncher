# SkyLauncher — latest source + local/offline installer project

See **QUICK-START.md** first for the short GitHub Pages and release setup.

## What is included

| Path | Purpose |
|---|---|
| `src/SkyLauncher.java` | Current Java launcher (UI, grayscale themes, update prompt, desktop shortcuts, mods, game installation) |
| `src/SkyLauncherSetup.java` | Previous optional cross-platform GitHub bootstrap updater; included as source and JAR, **not used** by the offline installers |
| `skylauncher.pyw` | Python launcher reference |
| `docs/` | GitHub Pages site; read-only GitHub Releases download links |
| `.github/workflows/build.yml` | Builds real native Windows/macOS/Linux installers with Java included from repository source, then publishes tagged releases |
| `windows-installer/main.go` | Lightweight local-only Windows setup source, with embedded application JAR; requires preinstalled Java 17+ |
| `windows-installer/bundled/SkyLauncher.jar` | Application embedded in lightweight local-only setup |
| `release-ready/SkyLauncher.jar` | Portable Java application (Java 17+ required) |
| `release-ready/SkyLauncherSetup.jar` | Optional online update/setup app (Java 17+ required) |
| `build-windows-full-offline.ps1` | Locally build a full Windows native installer (bundled Java); requires JDK 21+ and WiX |
| `icons/` | **Empty** icon slots documented in README |
| `tests/` | Website tests |

## Two Windows installer choices

- **`SkyLauncher-Windows-Local-Setup.exe` (included separately and in the full bundle):** Runs locally, **no GitHub/network access during installation**; uses embedded SkyLauncher.jar and **requires Java 17+ already installed**. Creates a desktop shortcut if requested. Does not require admin rights under normal account policy.
- **Native jpackage Windows EXE (GitHub Actions / PowerShell build):** Bundles its own Java runtime with SkyLauncher. Does **not** fetch the launcher from GitHub or the internet during install. Can be installed without preinstalled Java. Its source and build workflow are in this project; the resulting Windows-built EXE is not in this Linux-built bundle.

These are **not** the older download-from-GitHub bootstrap installer. The original Java startup update checker can still query GitHub **after launching**. The installer itself never fetches code or packages.

## Important notes

- This bundle has **no custom app-icon artwork**; add your own images into the documented locations when ready.
- Java self-tests and website unit tests are run during package preparation. This environment cannot execute Windows GUI EXEs, so the Windows installer needs testing on a Windows computer.
- The native `.exe` generated by GitHub Actions is not signed; Windows SmartScreen may warn. macOS native releases may require signing/notarization to avoid warnings.
- CurseForge remains deferred until the external server API is ready.
- The launcher shares configuration and instances with the Python version in `~/.ghmodlauncher/`. Back up your data before testing new versions.

## Java UI matching the Python launcher screenshot

The Java launcher now has the screenshot-style header, profile row, two tabs (Mods and Settings),
scrolling modpack/add-mod/search/tracked-mods panels, fixed activity log, and fixed bottom launch bar.
The same five black-to-white background presets and the built-in accent color picker remain in Settings.
The new **Sync to official launcher** button writes a profile to the official launcher only after
asking for confirmation, checking its installed version, and backing up `launcher_profiles.json`.
The app icon is intentionally absent; put your own optional assets in `icons/` later.

For a safe offline *visual* preview without the update and shortcut prompts, run
`java -jar release-ready/SkyLauncher.jar --ui-preview` (this is only a UI testing option).
The installed launcher still checks for updates on startup as before.

## Easier settings and custom colors

The **Settings** tab now keeps only the choices most people need:
- **Minecraft version** and **mod loader**
- **RAM (MB)** (4096 = 4 GB)
- **Extra JVM arguments**, for people who need custom Java settings
- **Light/dark shade preset** (five black-to-white presets)
- Three built-in color pickers for **background**, **text**, and **accent**; optional `#RRGGBB` input, Apply and Reset
- **Create desktop shortcut**

The **Advanced settings...** button opens a separate optional dialog for paths,
loader version, fullscreen, environment variables, custom commands, tokens, etc.
These existing values are **preserved**, not deleted when the simplified tab is used.
Appearance choices are saved in `~/.ghmodlauncher/config.json` and remembered between runs.
The color chooser is built into Java Swing; no plugins or other apps are needed.


## Portable Linux installer (including CachyOS / Arch)

In addition to the `.deb` package, `.github/workflows/build.yml` builds these
portable GitHub Release assets after the compatibility tests pass:

- `SkyLauncher-Linux-Portable-x86_64.tar.gz`: Linux x64, includes Java 21
- `SkyLauncher-Linux-Portable-arm64.tar.gz`: Linux ARM64, includes Java 21
- `SkyLauncher-Linux-Portable-Java-Required.tar.gz`: Java 17+ required; can
  also be used if the bundled runtime is incompatible with the distribution

The archives have files **at the archive root** (no enclosing directory). Users
should extract one into a new folder, run `./run.sh`, or run `./install.sh` to
add a menu entry and optionally create a desktop shortcut. Installation does
not use sudo, change the OS, download anything, or touch `~/.ghmodlauncher`.

The x64 bundle is built on Ubuntu 22.04 for wider glibc compatibility; the ARM64
bundle is built on Ubuntu 24.04 ARM. Systems using musl rather than glibc
(Alpine) should use the Java-required archive and their own compatible Java.

Run the package tests locally with:

```bash
bash tests/ci-build.sh
bash linux-portable/package.sh build/SkyLauncher-ci.jar dist --bundle-java
bash tests/test_linux_portable.sh dist/SkyLauncher-Linux-Portable-x86_64.tar.gz
```
