# Empty website logo slot

There is **no supplied SkyLauncher icon**. The website shows blank placeholders.

To use your own picture, upload `icon.png` into this `docs/` directory and publish GitHub Pages. It will appear in the website header, hero section, and footer, and become the browser favicon. Suggested square PNG: 1024×1024 pixels.

This is separate from the native app icons under `icons/`.
