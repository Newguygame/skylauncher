SkyLauncher for Linux
=====================

Run without installing:
1. Unpack all files into a new folder.
2. Open a terminal in that folder.
3. Run: ./run.sh

Add SkyLauncher to your Applications menu:
  ./install.sh

You can choose whether to add a desktop shortcut.

Remove the installed app:
  ~/.local/share/skylauncher/uninstall.sh

Your Minecraft worlds, mods, and settings are kept when you remove the app.

If Java is not included in your download, you need Java 17 or newer.
